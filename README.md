# DormCycle

A student marketplace for college dorms: buy, sell, message, and arrange item handoffs on campus.

This repository currently contains the **landing page** only (Next.js, TypeScript, Tailwind CSS). Listings shown are samples. Accounts, real listings, chat, and payments will be added later.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
